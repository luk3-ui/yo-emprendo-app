Inicio / Digital (App) / Color

Color

Teal como acento principal; Azul, Índigo y Ciruela como acentos secundarios.

Lo esencial

Teal como acento principal; Azul, Índigo y Ciruela como acentos secundarios.

El detalle

Justificación: H7 (Memoria espacial).

El menú de inicio se estructura por colores semánticos (chunking visual) para facilitar la memoria espacial. La guía impresa tiene las mismas secciones, cada una con un color propio (C4).

Versión actual en la app

Además del teal de identidad, cada camino tiene su par de colores: Tienda índigo (#c5c4f9 / #4846b3), Productos azul (#c3d3f6 / #1e40af), Pedidos violeta (#e3c4e8 / #701a75) y Postularme a una feria rosa (#e9c0c6 / #ba1650). El amarillo #ffc93e queda reservado para los avisos de ayuda.

Actualizado con el prototipo de noviembre de 2026. Registro completo: Decisiones de la app.
